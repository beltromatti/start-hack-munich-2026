Three rules keep it simple.

  1. 1One agent per deal.

    Giulia holds the whole thread, from the first mail to the booking.

  2. 2Prices come from code.

    The model writes the mail. Every total and date is computed.

  3. 3Your word wins.

    Write Giulia one sentence. Giulia follows it from then on.

One agent with one session per mail thread. Every price, date and recipient is computed or checked by code. A person can write into any session and Giulia follows.
